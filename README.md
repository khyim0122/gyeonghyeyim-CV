# Academic homepage

A lightweight, responsive academic homepage built as a static GitHub Pages site—no build tools required.

## Personalize it

1. Edit `index.html` and replace the bracketed sample text, `Your Name`, initials (`YN`), email address, university, and social links with your details.
2. Add your own news, publications, teaching experience, and education. Replace the sample publication links with real URLs.
3. Upload your CV PDF to the repository root as `cv.pdf` (or update the download link in `index.html`).
4. Optionally replace the abstract initials card in `index.html` with a profile photo.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub Pages will publish the site at the repository's Pages URL once deployment completes.

The tab navigation works with mouse, touch, and keyboard (left/right arrows, Home, and End). Tab selection is reflected in the URL fragment so sections can be linked directly.
